# 📈 엔비디아(NVIDIA) 최근 1개월 주식 분석 대시보드

초보자도 한눈에 이해하기 쉬운 **엔비디아(NVDA)**의 최근 1개월 주가 추이 및 주요 동향 분석 대시보드입니다.

---

## 📌 프로젝트 소개
- **대상 기업**: NVIDIA Corporation (나스닥: `NVDA`)
- **분석 기준 기간**: 2026-10-21 ~ 2026-11-20 (장마감 종가 기준)
- **제공 기능**:
  - **3대 테마 전환**: 🌅 선셋 글래스(기본), 🟢 NVIDIA 시그니처 다크, 💬 카카오톡 라이트 스타일
  - **인터랙티브 종가 차트**: Chart.js 기반 일별 종가선 및 23거래일 원시 데이터 표 전환
  - **사실 vs AI 해석 비교**: 확인된 공시 수치와 시장 해석을 나란히 분리 배치
  - **관련 뉴스 10선**: 공식 보도자료 및 외신 기사 수록 (본문 열람 7건 요약 / 미열람 3건 상태 명시)
  - **보고서 및 인쇄**: PDF 인쇄 최적화 스타일 및 단독 실행 파일 제공

## 📂 파일 구성 안내
| 파일명 | 설명 |
| :--- | :--- |
| **`index.html`** | GitHub Pages 배포 메인 대시보드 (반응형 웹, 테마 전환, 차트 탑재) |
| **`stock-report.html`** | 배경 이미지가 Base64로 내장되어 인터넷/외부 파일 없이 단독 실행 가능한 리포트 |
| **`sunset_bg.jpg`** | 선셋 글래스 테마 배경 이미지 |
| **`nvda_1month_data.json`** | 1개월간 일별 시가·고가·저가·종가·거래량 원본 데이터 (JSON) |
| **`nvda_1month_raw.csv`** | 1개월간 일별 시가·고가·저가·종가·거래량 원본 데이터 (CSV) |
| **`nvda_news_checked.json`** | 수집된 뉴스 기사 및 원문 링크·열람 상태 데이터 |
| **`nvda_rss.json`** / **`nvidia_official_checked.json`** | 뉴스 RSS 및 공식 보도자료 원본 수집 데이터 |
